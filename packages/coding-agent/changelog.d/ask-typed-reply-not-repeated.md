### Fixed
- A reply typed into `Other` is no longer answered with the same question again. `ask` now refuses a call that repeats, with the same text and options, a question you just answered by typing, so the agent has to use what you wrote. Deep-interview reads the typed text first: a question gets an explanation and a plainer rewording, "you decide" goes to the auto-answer step, a correction is applied before the next question, and on the Round 0 and intent-review confirmations (where typed text is still not an approval) the proposal is revised to match your reply before it is shown again. A typed reply to the "is this interpretation right?" confirmation is folded into the interpretation instead of sending you back to the original question.
